导出术语与概念

全库 JSON 是包含文章的完整语义快照。其他格式有各自表达边界，请同时保存导出报告。

JSON / Markdown

JSON 保留结构；Markdown 用于人工阅读。项目表包含全部译法备选，不能只凭“方案选用”推断其适用于所有作品。

CSV

全库每行一个义项，项目表每行一条译法。多值字段使用 JSON 单元格，文件采用 UTF-8 BOM。

TBX

按概念和语言组织义项，条件及状态保存在说明中。通用 CAT 软件未必能执行这些条件，不应无条件自动替换。

SKOS

用于概念组织，不替代词条、证据和译法数据。草稿关系与可能等价关系保留独立状态，不断言 exactMatch。
